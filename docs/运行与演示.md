# 拾物 × 客服咪：运行与演示

这是一个本地模拟电商社交平台。商品浏览、好友、私聊、群聊和 AI 工具相互联动；模拟账号方便评审在两个标签页中操作。

## 快速启动

需要 Python 3.11 或更新版本。新平台不需要 GPU、模型下载、MySQL 或 Neo4j 即可运行。

```powershell
cd D:\zhinengdianshang\er_graph
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

本机已有可用环境，可直接运行：

```powershell
& D:\zhinengdianshang\graph2\python.exe run.py
```

打开 http://127.0.0.1:8000 。首次启动会创建 `data/runtime/platform.db`，包含 5 个演示账号、12 件演示商品、一个讨论群和一段示例聊天。普通重启不会覆盖已有操作。

端口占用时，设置 `$env:PORT='8001'` 后再运行。默认仅监听本机回环地址。浏览器右下角的账号入口可切换身份；在另一个标签页选择不同账号即可互聊。

## 三到五分钟演示脚本

1. **产品用途（约 20 秒）**：展示商城首页。介绍“拾物”让用户和朋友讨论商品，客服咪在侧边帮助对比和总结。
2. **商城（约 40 秒）**：筛选耳机，进入详情；将 Redmi Buds 6 与 FreeBuds 6i 加入对比。在助手中生成对比表，解释价格、参数和数据来源。
3. **好友（约 40 秒）**：林一向许知夏发送申请。在另一标签页切换许知夏并接受。双方开始私聊，发送文字或商品卡片。
4. **群聊（约 40 秒）**：林一选择好友建群；两边分别发送预算、用途与参数偏好，验证另一边实时收到。
5. **AI 联动（约 60 秒）**：也可以直接使用预置“周末好物研究所”。在该群的助手侧栏点击“商品对比”，不手动选择时使用聊天中分享的商品。随后点击“聊天总结”，核对需求、成员观点、明确结论、待确认点和待办，并点击消息编号定位原话。
6. **分享与连续咨询（约 30 秒）**：预览后把对比发回群中；问“换成华为，预算 600 元以内”，展示条件承接。新消息到来后，旧摘要会显示更新提示。
7. **工程质量（约 30 秒）**：刷新保留数据；展示测试报告，并解释当前本地模式与可选模型、图谱集成的边界。

## AI 模式

### local：默认可运行

商品筛选和对比使用结构化目录；聊天总结使用按作者、需求、结论、问题与待办分类的原文摘录。它有实际数据与原消息依据，不会把本地模式伪装成模型生成结果。

- 支持 2–4 件商品对比、目录检索和基本追问条件承接。
- 摘要可以选最近 50 条、全部（上限 1000 条）或带时区的时间范围。
- 本地总结使用规则摘录，表达归纳能力有限；涉及否定、反问或复杂承诺时需核对引用。
- 当前会话之外的消息不会被默认合并；账号与 AI 会话分别保存。

### deepseek：可选大模型模式

在本地 `.env` 中设置，随后重启服务：

```dotenv
AI_MODE=deepseek
DEEPSEEK_API_KEY=填写你自己的有效密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
```

启用后，商品问题可通过模型组织答案；不超过 200 条的聊天摘要使用结构化模型输出，并检查所有引用 ID 是否属于本次范围。更长的范围采用本地分组摘录。模型异常、超时或引用校验失败时，界面明确提示并返回本地依据结果。

商品对比的表格与字段始终来自目录。模型不能补出目录缺失的库存、价格、规格。本轮未使用历史代码中的已暴露密钥，也未实际验证云端模型调用。此前已经暴露的密钥需要在服务商控制台撤销并更换；本地迁移和 Git 忽略无法撤销历史泄露。

## 业务库快照

安装可选集成依赖，并在 `.env` 填写 MySQL 配置：

```powershell
python -m pip install -r requirements-integrations.txt
python scripts/import_mysql_catalog.py
```

脚本读取 gmall 的 SKU、品牌和类别，按 `mysql-原SKU编号` 写入平台 SQLite；可重复执行，更新快照不创建重复商品。它不修改原 MySQL 或 Neo4j。导入时间、SKU 和来源在商品详情及 AI 结果里展示。本机已导入 43 条业务商品，连同演示商品共 55 条。

原始重量字段没有可靠单位元数据，界面保留为“重量（原始值）”；不推断单位。缺失参数显示“暂无数据”。插画用于示意，价格均为快照，并非实时售价或库存。

## Neo4j 与原训练流程

原 `src/ner`、`src/datasync`、图谱索引和实验问答代码保留。新平台不会在启动时加载 BERT 或向量模型。

`GET /api/products/mysql-{SKU编号}/graph` 提供固定、参数化、限 30 条、超时 5 秒的邻接图谱查询。需要安装可选依赖，并配置具有读权限的独立账号：

```dotenv
NEO4J_URI=neo4j://127.0.0.1:7687
NEO4J_READ_USERNAME=你的只读账号
NEO4J_READ_PASSWORD=你的密码
```

未配置时返回明确的 503 状态，不会展示编造的图谱路径。演示商品返回“未关联业务图谱”。只读图谱账号尚未在本机配置，本轮未进行在线图谱问答验收。

原同步器已改为按稳定 id 合并，再更新属性。`ensure_unique_ids` 可建立约束，但执行前要先做 Neo4j 完整备份、检查并清理历史重复 id；本轮没有对原图谱执行同步、建约束、删节点或重训模型。原实验问答入口不是新平台的公开接口；如果单独使用，需自行安装原 LangChain、Transformers 等训练/实验依赖，并配置模型及只读图谱账号。

## 数据与运行边界

- 账号切换是本地演示入口，不具备生产注册登录、手机号验证、密码管理或实名身份认证。不要将本演示直接暴露为公网多用户系统。
- 首版不包含真实付款、发货、微信采集或订单履约。
- 群主可以邀请自己的好友、改名或移除成员；成员可退出；群主退出前需要先移除其他成员。
- 新加入的成员可查看群内历史；退出或移除后不能继续访问聊天或 AI 历史。
- AI 分析私有保存；只有点击“预览并发送到聊天”才会分享。聊天分析只允许发送回原会话。
- WebSocket 在单个服务进程内推送；本地 SQLite WAL 持久化。不适用多 worker/多节点部署；扩展时需共享消息总线和账号认证。
- `.env`、运行数据库和测试日志被忽略，不能作为交付源码上传。现有 `.env` 已从 Git 索引移除，但仍保留在本机。
